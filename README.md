# bump-it wrapper fixture

Public, disposable repository for a real bump-it Gradle wrapper update. It has
one Java class and one dependency-free test (`fixtureTest`, included in `check`).

```sh
./gradlew check --no-daemon
```

The wrapper started at Gradle 9.7.1. bump-it's PR #1 moved it to 9.8.0, and #1
was merged on 2026-10-08 (b74bef6), so main's wrapper is now Gradle 9.8.0. The
wrapper files are generated by real Gradle distributions and include the official
distribution SHA-256. [VALIDATION.md](VALIDATION.md) records the 9.7.1 run.

The Actions `Check` workflow runs on main and PRs. It checks out directly with git
so action-pin updates do not distract from this wrapper-only fixture. There are no
third-party build dependencies. The `supply-chain` workflow, added in #2, calls the
supply-chain gate pinned to v0.6.0. The gate runs on pull requests, pushes to main
and manual dispatch; it has no schedule (removed 2026-10-12) and, since v0.4.0, no
open-PR rescan. The gate pin is an own Action (`ownPackages`), so bump-it's routine
may move it. `.github/supply-chain.json` sets the seven-day window and the root
Gradle build; the operator opts in through the separate bump-it `agent.yaml`.

This fixture isn't part of regular tool passes: it runs only in release-candidate
passes that opt fixtures in (`SUPPLY_CHAIN_FIXTURES=1`). The tools are at v0.4.2.

Nothing is published or merged by the tools here. The operator reviews the four
wrapper files and CI in the PR bump-it creates.

[EXPECTED.md](EXPECTED.md) separates the historical 9.7.1 run from the live wrapper rule.
